### If you are using ProbeJS instead of ProbeJS Legacy, check [this extension](https://marketplace.visualstudio.com/items?itemName=Prunoideae.probejs) instead

Extended IDE support for typings generated by [ProbeJS Legacy](https://github.com/ZZZank/ProbeJS-Legacy)

## Settings

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| `probejs-legacy.filterJavaImports` | boolean | `true` | Filter auto-imports from `java:` module paths |
| `probejs-legacy.redirectJavaImports` | boolean | `true` | Redirect `java:` imports to `Java.loadClass()` calls |
| `probejs-legacy.redirectTemplate` | string | `const ${class_name} = Java.loadClass("{package_name}.{class_name}")` | Template for redirected imports |

## Extension Host Testing

1. Open this project in VS Code
2. Press `F5` to launch the Extension Development Host
3. Open a `.ts` file to activate the plugin

## Build

```bash
npm run build      # compile extension + plugin
npm run package    # build + package into .vsix
```
